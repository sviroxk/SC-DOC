SC

Язык SC и его компилятор: C++ и LLVM, на выходе LLVM IR. Эта страница собрана из спецификации языка (docs/spec.md). Каждый пример на ней компилируется и запускается тестами компилятора, и его вывод сверяется с блоком «Вывод».

Исходный код компилятора на GitHub ↗ · спецификация

SC пока прототип. Что ещё не сделано — в разделе «Известные ограничения».

Сборка

Нужен C++ компилятор и LLVM 18 (llvm-config). В клонированном репозитории:

./build.sh
./test.sh
timeout 10 ./sc hello.svx > hello.ll && lli hello.ll

1. Программа

Файл .svx — это последовательность объявлений и операторов. Код верхнего уровня выполняется сверху вниз, отдельная функция main не нужна (имя main занято). Комментарии: // до конца строки. Оператор заканчивается ;.

Программа

// вывод
print("Привет, мир!");
print(42);

Вывод

Привет, мир!
42

Сборка и запуск: ./sc файл.svx > файл.ll, затем lli файл.ll или llc и clang. Код выхода компилятора: 0 — успех, 1 — синтаксическая ошибка, 2 — семантическая, 3 — внутренняя ошибка компилятора. Ошибка выполнения печатает SC runtime error: <что> at line L, column C и завершает программу с кодом 1.

Точные имена (i32, f64 …) — основные, короткие — их алиасы. Целые литералы по умолчанию имеют тип i32, дробные — f64. Литералы: 42, 0x2A, 0b101010, 1_000, 1.5, 2e3, 'a', "текст".

3. Переменные

Программа

int a = 1;          // тип и значение
let b = 2;          // тип выводится из значения
let c: i64 = 3;     // let с явным типом
const d: int = 4;   // константа
int e = 5;  // старая форма объявления, работает так же
a = a + b;
a += c;             // составные: += -= *= /= %=
a++;
print(a + d + e);

Вывод

16

Имена видны в своём блоке { } и во вложенных. Внутренний блок может объявить то же имя заново (затенение). Использовать переменную до присваивания нельзя.

Не компилируется

int x = 1;
int x = 2;

Ошибка (часть сообщения)

повторное объявление 'x'

4. Операторы и политика целых

Арифметика + - * / % **, целочисленное деление с округлением вниз //, побитовые & | ^ ~ << >>, сравнения < > <= >= == !=, логические && || ! (с коротким замыканием), тернарный условие ? a : b. -2 ** 2 равно -(2 ** 2).

Программа

print(7 / 2);
print(7 % 3);
print(2 ** 10);
print(-2 ** 2);
print(17 // 5);
print(6 & 3);
print(1 << 4);
int v = 4;
print(v > 3 ? 10 : 20);

Вывод

3
1
1024
-4
3
2
16
10

Значение молча не портится. Для целых:

  • переполнение + - * **, унарного минуса, MIN / -1 — ошибка выполнения integer overflow;
  • деление и остаток на ноль — division by zero;
  • сдвиг на число вне 0..ширина-1 — shift amount out of range;
  • если такое видно из констант, это ошибка компиляции;
  • запись результата в узкий тип (u8 x; x += 1;) проверяет диапазон.

Не компилируется

print(2147483647 + 1);

Ошибка (часть сообщения)

переполнение: значение константного выражения 2147483648 не помещается в тип 'int/i32'

Не компилируется

int a = 5;
print(a / 0);

Ошибка (часть сообщения)

деление на ноль

Арифметика над i8/u8/i16/u16/char выполняется в i32.

Преобразования

Неявно разрешено только то, что не теряет значение: расширение целого той же знаковости, беззнаковое → более широкое знаковое, f32 → f64, любое целое → f64, целое до 16 бит → f32. Константа, которая точно помещается в тип, тоже разрешена (u8 b = 200;). Остальное требует явного приведения (T) x. Явное приведение проверяет диапазон: константа вне T — ошибка компиляции, значение во время выполнения — value out of range for type 'T'.

Программа

i64 big = 5000000000;
int small = 7;
i64 wide = small;
f64 f = 3.75;
print((int) f);
print(wide);
print((i64) big + 1);
u8 b = 200;
print(b);

Вывод

3
7
5000000001
200

Не компилируется

i64 a = 1;
int b = a;

Ошибка (часть сообщения)

нужно явное приведение

5. Условия и циклы

Программа

int x = 3;
if (x == 1) {
    print(1);
} else if (x == 3) {
    print(3);
} else {
    print(0);
}
int n = 0;
while (n < 2) { n += 1; }
print(n);
for i in 0..3 { print(i); }
for j in 1..=2 { print(j); }
int[] values = [5, 6];
for value in values { print(value); }
repeat (2) { print(9); }
loop {
    n += 1;
    if (n == 4) { break; }
    if (n == 3) { continue; }
}
print(n);

Вывод

3
2
0
1
2
1
2
5
6
9
9
4

for i in a..b — от a до b - 1, a..=b — включительно. repeat (n) повторяет блок n раз. loop — бесконечный цикл, выход через break или return. Условие — bool или целое (ноль — ложь). Код после return/break/continue в том же блоке — ошибка компиляции.

6. Функции

Программа

fn int square(int x) { return x * x; }
fn void show(int x) { print(x); }
fn bool even(int n);                 // объявление без тела
fn bool odd(int n) { if (n == 0) { return false; } return even(n - 1); }
fn bool even(int n) { if (n == 0) { return true; } return odd(n - 1); }
show(square(5));
print(even(10));

Вывод

25
1

Функцию можно вызвать до её определения. Объявление без тела должно совпадать с определением по типам. Функция с результатом должна возвращать значение на всех путях (бесконечный loop без break тоже считается). Вложенные функции, перегрузка и имена встроенных функций (max, sqrt …) как имена своих функций запрещены. Аргументы разделяются запятыми.

7. Структуры

Программа

struct Inner { int x = 0; }
struct Pair {
    int a = 1;
    Inner inner;
}
fn int sum(Pair p) { p.a = 100; return p.a + p.inner.x; }
Pair value = { a = 2; inner = { x = 0; }; };
value.inner.x = 5;
value.a += 1;
print(sum(value));
print(value.a);

Вывод

105
3

struct Имя { поля } объявляет структуру; поля могут иметь значения по умолчанию. Переменная-структура: Имя x; или с инициализатором Имя x = { поле = значение; };. Параметр-структура: fn int f(Имя x). В функцию структура передаётся копией. Возвращать структуру из функции пока нельзя. Рекурсивная структура (поле своего же типа) запрещена.

8. Массивы

Статический массив имеет фиксированную длину; индекс проверяется (константный — при компиляции, остальные — при выполнении).

Программа

int[] a = [1, 2, 3];
a[0] = 10;
a[1] += 5;
print(a[0] + a[1] + a[2]);

Вывод

20

Динамический массив создаётся new T[n]: длина n, элементы равны нулю. Методы: push(x), pop() (возвращает элемент, у пустого — 0), resize(n), len(), cap().

Программа

ptr v = new int[2];
v[0] = 4;
v.push(7);
print(v.len());
print(v.pop());
print(v[0]);
drop v;

Вывод

3
7
4

Не компилируется

ptr v = new int[2];
print(v[0]);
fn int g(ptr p) { return 1; }
print(g(v));

Ошибка (часть сообщения)

пока нельзя передать в функцию

9. Указатели и null

&x — адрес переменной, *p — значение по адресу, null — пустой указатель (допустим только для ptr). Разыменование null — ошибка выполнения null pointer dereference. Указатели сравниваются только через == и !=.

Программа

int x = 5;
ptr p = &x;
*p = 9;
print(x);
ptr q = null;
if (q == null) { print(1); }

Вывод

9
1

Не компилируется

int a = null;

Ошибка (часть сообщения)

null и указатели допустимы только для типа ptr

10. defer и drop

defer операция; выполняет операцию при выходе из текущего блока, в обратном порядке. При return сначала вычисляется значение, затем выполняются defer. Внутри defer нельзя объявлять переменные и делать переходы.

drop x; освобождает динамический массив или закрывает файл. После drop имя использовать нельзя, повторный drop — ошибка компиляции, как и drop внешней переменной внутри цикла или функции.

Программа

fn int f(int x) {
    ptr v = new int[2];
    defer drop v;
    defer print(1);
    v[0] = x;
    return v[0] + 1;
}
print(f(4));

Вывод

1
5

Не компилируется

ptr v = new int[2];
drop v;
print(v[0]);

Ошибка (часть сообщения)

'v' используется после drop (строка 2)

del p; освобождает память по указателю без проверок (ручной режим).

11. Строки

Программа

string s = "hello";
print(s);
print(len(s));
print(s == "hello");
print(s != "x");
ptr r = replace("a-b", "-", "+");
print(r);
print(str(42));

Вывод

hello
5
1
1
a+b
42

len(s) — длина строки, s == t — равны ли строки, replace(s, a, b) — копия s с заменой a на b, str(x) — число в строку. Строки сравниваются через == и != (по содержимому). Сложение + пока не поддерживается.

12. Ввод

input_int("подсказка") читает число, input_str("подсказка") — строку.

Программа

int n = input_int("");
string name = input_str("");
print(n * 2);
print(name);

Ввод

21

Вывод

13. Файлы

open(путь, режим) открывает файл ("w", "r", "a"; не открылся — ошибка выполнения), write(f, строка) пишет, read(f) читает строку, close(f) или drop f закрывает.

Программа

file out = open("spec-file.txt", "w");
write(out, "строка");
drop out;
file inp = open("spec-file.txt", "r");
print(read(inp));
close(inp);

Вывод

строка

14. Импорт

import "путь.svx"; подставляет другой файл (путь относительно текущего). Циклические импорты и отсутствующие файлы — ошибка. Пространств имён нет. Стандартная библиотека: stdlib/math/math.svx (math_abs, math_min, math_max, math_is_even).

15. Встроенные функции

sqrt, abs, pow, max(a, b), min(a, b), floor (вниз), ceil (вверх), round (округление), rand() (случайное целое), len, replace, str. Эти имена зарезервированы: так нельзя назвать свою функцию или переменную.

Программа

print(min(3, 7));
print(abs(-4));
print(floor(2.7));
print(ceil(2.1));
print(round(2.5));
print(sqrt(16.0));

Вывод

7
3
4
2.000000
3.000000
3.000000
4.000000

17. Известные ограничения

  • Нет обобщённых типов, перечислений, Option/Result, сопоставления с образцом, замыканий, интерфейсов, пространств имён, многопоточности, FFI.
  • Структуры нельзя возвращать из функций; динамические массивы нельзя передавать в функции и возвращать.
  • Строки из str(), ввода и replace пока не освобождаются (утечка, не порча памяти).
  • Сырой ptr не знает длину: индекс p[i] проверяется только на null.
  • Модель памяти (автоматическое освобождение и проверки владения) ещё не сделана; del — ручной режим без проверок.
  • Строки: нет +, ==, работы с Unicode.
